An eroding VFX material and a quick-editing tool for Unreal Engine 4, built to be easy for artists to edit and test.

Overview

This is my practice of VFX creation and tool development. When I built the material and the tool, I tried to think about what artists need in VFX creation, and how to make the tool easy to use during development.
